# Bagu 五 Tab 移动导航与触摸修复设计

## 目标

修复 iPhone Expo Go 中页面无法点击和滚动的问题，并降低首屏信息密度。应用采用五个稳定主入口：首页、今日、知识库、复习、我的。学习路径、课程、知识详情、简历管理和模拟面试成为二级页面。

## 问题判断

设备成功加载 SDK 54 bundle，Metro 没有运行时崩溃；但滚动和所有按钮同时失效，因此问题不属于单一路由或单个 `Pressable`，而属于根层交互链路。最近加入的全局 Sound Provider 包裹整个导航，同时 SDK 54 开启了实验性 React Compiler。修复采取隔离策略：根层只保留进度状态和标准 Router，音频下沉到使用它的页面，关闭实验性编译，并移除手工重复的底部导航。

## 导航结构

根布局使用 Stack，包含一个 `(tabs)` 分组和所有二级页面。`(tabs)` 使用 Expo Router 标准 Tabs：

1. 首页：连续学习、XP、今日进度、继续学习主按钮、通用八股与简历项目入口、模拟面试入口。
2. 今日：只展示当天计划、预计用时和任务状态；进入任务后打开二级学习路径或复习页面。
3. 知识库：保留搜索、领域筛选、收藏和知识卡。
4. 复习：保留课程、通用知识与项目题的统一队列。
5. 我的：保留统计、项目档案、模块掌握和音效开关。

二级页面包括学习路径、课程答题、完成页、知识详情、简历管理和模拟面试。二级页面隐藏底栏并提供明确返回入口。

## 页面密度

首页不再直接渲染完整 Transformer 路径。它只显示一张今日进度主卡、两张模块入口卡和一张模拟面试入口卡。所有主卡均有单一明确动作，不再出现无行为的按钮造型。

“今日”页最多显示三个任务：一个通用课程、一个复习任务、一个可选项目任务。任务卡只呈现标题、来源、预计时长、状态和动作，详细知识内容进入下一层。

完整路径移到独立的 `/path` 页面，集中展示当前 Transformer 单元和节点，不与首页入口竞争注意力。

## 触摸与音效隔离

- 删除手工 `BottomNav` 在各页面的重复挂载，使用 Router Tabs 统一管理触摸与导航。
- 根 Stack 不再由 Sound Provider 包裹。
- 答题页本地加载答对、答错音效；完成页本地加载完成音效。
- 音频播放错误继续静默降级，不影响状态和路由。
- 关闭 `experiments.reactCompiler`，保留 typed routes。
- Modal 仅在存在实际内容时挂载，隐藏状态不保留透明触摸层。
- 所有列表保证内容区域与底栏之间有安全底部间距。

## 数据流

现有 Progress Provider 继续作为唯一学习状态来源，保存 XP、课程完成、复习队列、收藏、简历项目档案和音效开关。五个 Tab 仅读取或调用该上下文，不创建第二份进度状态。

今日任务从现有课程解锁状态、复习队列和项目档案派生，不新增服务端或伪造 AI 推荐。以后接入推荐算法时，只替换今日任务选择器。

## 测试与验收

1. Expo Doctor 18/18、TypeScript 和 ESLint 通过。
2. Web 与 iOS bundle 均成功生成，音频资源进入 iOS bundle。
3. 五个 Tab 都可点击并切换；当前 Tab 状态清晰。
4. 首页可滚动，继续学习、通用知识、项目档案和模拟面试入口都进入正确页面。
5. 今日任务可进入学习路径、复习或项目档案。
6. 二级页面返回正常且不显示底栏。
7. 答对、答错、完成音效继续工作；关闭音效后不播放。
8. Expo Go tunnel manifest 为 `exposdk:54.0.0`，物理 iPhone 可重新扫码验证。

## 非目标

本轮不增加新的知识内容、账号系统、云端同步或 AI 解析。重点是稳定触摸、清晰层级和移动端可用性。
