# Bagu 方案 A：概念手册与统一视觉系统设计

## 目标

把 Bagu 从“题目列表加文字图标”改造成路径优先、内容可查、视觉统一的算法面试学习产品：进入首页直接看到学习路径；知识库以概念手册呈现；界面不使用 Emoji 或字符冒充图标；保留公式中的数学符号。

## 设计依据

- 借鉴 Duolingo 的圆形、圆角矩形和圆角三角形语言，以及低文字密度的路径式学习体验，但不复制其角色、图形资产或品牌细节。
- Expo SDK 54 官方支持 `react-native-svg`。图标直接由 SVG 路径绘制，不依赖图标字体，降低 Expo Go 首次加载和字体缓存导致的缺图风险。
- 所有频繁操作图标使用同一套代码原生组件；原创位图只用于学习伙伴插画，避免图片资源泛滥。

## 信息架构

### 学习路径

- 首页仍以 Unit → Section → Learning Node 组织课程。
- Section 内保留轻微左右摆动的节点节奏，移除中间引导线。
- 节点保持圆形立体按钮，但用同一套 SVG 图标表达主题、完成、锁定状态。
- 当前学习节点附近显示一次原创 Bagu 学习伙伴，提供视觉聚焦；不在每个节点重复。

### 知识库

- 列表标题必须是概念名词，例如“缩放点积注意力”，而不是“为什么要除以根号 d_k？”。
- 卡片显示概念标题、简短定义和难度，承担检索而非答题功能。
- 详情页按手册结构组织：核心概念、工作机制、公式与流程、关键结论、对比与边界、常见误区、面试追问、参考来源。
- 面试问题保留在独立 `interviewQuestion` 字段中，只用于模拟面试与“面试追问”，不污染知识库浏览体验。

## 图标系统

- 新建 `AppIcon`，以 `react-native-svg` 绘制圆角线性图标。
- 统一使用圆头、圆角连接和 2.2–2.5 的描边；图标颜色继承所在领域主题色。
- 图标可放在淡色圆角底中，保证点击范围和层级一致。
- 覆盖底部导航、课程节点、知识领域、搜索、收藏、关闭、返回、声音、进度、锁定、完成、简历和面试等所有界面图标。
- 类型层使用 `AppIconName` 联合类型，课程和领域数据只能引用有效图标键。

## 原创学习伙伴

- 角色为紫色书本形学习伙伴，使用圆形、圆角矩形和圆角三角形组成；薄荷绿作为辅助色。
- 手持一张学习卡，姿态积极，表情友好；不使用猫头鹰轮廓、不模仿任何已有吉祥物。
- 无文字、无 Logo、无水印。先在纯色键背景上生成，再移除背景并验证透明通道。
- 资产存放于 `app/assets/images/bagu-companion.png`，仅在路径焦点和少量空状态中使用。

## 数据兼容

- `KnowledgeCard` 增加可选 `interviewQuestion`，现有问句标题在组合阶段转换为概念标题，同时将旧标题保存在该字段。
- `LearningNode.icon` 和 `KnowledgeDomain.icon` 改为 `AppIconName`。
- 课程进度、收藏、复习队列与既有 ID 不变，避免本地状态失效。

## 错误与降级

- SVG 图标完全打包在 JavaScript 中，不需要网络下载；未知图标在类型检查阶段失败。
- 学习伙伴图片加载失败时不阻断节点点击和课程流程。
- 知识条目缺少对比或误区时，对应模块不渲染，不显示空容器。

## 验证标准

- 所有知识库列表标题不含问号；模拟面试仍能显示完整问题。
- `src/**/*.tsx` 不再出现界面 Emoji 或字符图标。
- 学习路径没有中间引导线，节点点击、解锁与进度逻辑不变。
- 内容验证、TypeScript、ESLint、Expo Doctor 全部通过。
- Web 与 iOS 导出成功，iOS manifest 和 bundle 可加载新组件与插画。
- 用清缓存的新 Expo 服务生成可供 iPhone Expo Go 扫描的二维码。

## 自审结论

该方案把“图标系统”和“知识内容结构”分离：SVG 负责高频交互一致性，原创插画负责品牌感，知识库负责查阅，练习模块负责出题。它不改变已有课程 ID 和进度存储，改造风险集中且可通过类型、内容和构建检查覆盖。
