# Bagu 公共学习版实施计划

## 目标

在现有 Expo 原型上交付一个可独立体验的第一版：用户无需上传简历即可学习通用八股；上传简历或手动填写项目信息后，可进入独立的项目深挖模块。知识库、复习和模拟面试复用同一套结构化知识数据。

## 本轮范围

1. 扩展结构化数据模型：领域、知识卡、来源、复习项、简历文件元数据和项目档案。
2. 首页提供“通用八股”和“简历项目深挖”双入口，并保留 Transformer 闯关路径。
3. 知识库提供搜索、领域筛选、收藏、加入复习和知识点详情。
4. 复习页统一展示课程、通用知识点和项目知识点，并显示来源标签。
5. “我的”展示学习统计、模块掌握度、简历状态和项目档案入口。
6. 简历模块支持选择 PDF、删除本地元数据、手动建立项目档案；AI 解析明确标注为后端待接入。
7. 模拟面试提供通用、简历、综合三种模式；没有项目档案时只限制后两种，不阻塞通用学习。

## 数据边界

- 第一版使用本地持久化，保存学习进度、收藏、复习安排、简历文件元数据和用户确认的项目档案。
- 不保存或伪造 PDF 正文解析结果。
- 公共知识内容为自主编写的结构化摘要，并保留论文或官方资料链接；不复制第三方题库正文。
- 后续服务端以 PostgreSQL 为主，语义检索需要时再增加 pgvector。

## 验收

- 四个底部主页面均为完整页面，不再含占位内容。
- 无简历用户可以完成通用学习、检索知识、收藏和复习。
- 知识库筛选与搜索可用，知识详情可打开并加入复习。
- 项目档案状态会本地保存，三种模拟面试入口会按状态正确启用。
- TypeScript、ESLint 与 Expo Web 导出全部通过。
