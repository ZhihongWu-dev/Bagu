# Bagu 课程与知识库扩充实施计划

## 1. 数据模型

- 扩展 `course.ts`：Section、Unit、四类 Exercise 联合类型、知识库关联字段。
- 保持旧 lesson id 和进度存储结构兼容。
- 增加纯数据校验脚本，断言课程与知识库数量和引用完整性。

## 2. Transformer 课程内容

- 将 `transformer-course.ts` 重组为 1 Section / 5 Units / 10 Lessons。
- 每个 Lesson 编写 4 道题，总计 40 道。
- 补齐题目涉及的关键词弹窗数据。

## 3. 多题型课程引擎

- 重构 Lesson 页为可前进的四题关卡。
- 实现单选、多选、排序、口述自评四种交互。
- 复用正确、错误、完成三个音效，并保证最后一题后才结算。

## 4. 学习路径

- CoursePath 按 Unit 渲染主题横幅和 lesson 节点。
- LessonNode 改为双层圆柱按钮，删除底边框厚度实现。
- 首页显示 Section 总进度和当前 Unit。

## 5. 知识库

- 扩充至至少 50 篇，满足六个领域配额。
- 列表页保留搜索与领域筛选，增加条目数量和专题组织。
- 详情页移除答题门槛，改为结构化阅读和可折叠模块。
- 增加相关条目跳转、误区、对比和来源展示。

## 6. 音效开关

- 用无平台差异的自绘胶囊 Switch 替换原生 Switch。
- 验证对齐、可访问性、触控尺寸和状态持久化。

## 7. 验证与交付

- 运行数据校验、TypeScript、Lint、Expo Doctor。
- 导出 Web 和 iOS bundle，验证关键路由。
- 审查触控遮罩和文本密度。
- 提交实现并重新生成 Expo Go 二维码。
