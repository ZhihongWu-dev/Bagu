# 学习路径优先与低文字界面实施计划

## 目标

将 `/` 从信息面板改为直接可操作的学习路径，合并重复的今日任务入口，把五个主 Tab 缩减为四个，并减少知识、复习、我的页面中的说明性文字。

## 1. 路由和导航

- 将 `(tabs)/index.tsx` 改为学习路径首页。
- 从 Tab 布局移除“今日”，删除对应路由文件。
- 将 `/path` 改为重定向 `/`，保留旧链接兼容性。
- 继续使用 Expo Router 标准 `Tabs`，不引入自定义导航覆盖层。

## 2. 学习路径组件

- 新增 `learning-status-bar.tsx`，只显示连续天数、XP、专注值。
- 新增 `unit-banner.tsx`，只显示单元名和完成进度。
- 将路径节点拆为 `lesson-node.tsx`，集中处理完成、当前、锁定、按压和无障碍状态。
- 精简 `course-path.tsx`：只负责路径布局和数据映射。

## 3. 首屏低文字改造

- 删除原首页的欢迎语、今日卡片、统计卡、模块卡和模拟面试推广。
- 当前节点仅显示“开始”和课程短标题，其他节点不显示正文。
- 保证 390 x 844 视口中当前任务与底部导航可见并可点击。

## 4. 次级页面减字

- 知识页删除英文眉题、引导段落和卡片摘要，只保留标题、搜索、筛选、知识点名称与收藏。
- 复习页删除英文眉题、说明段落和冗长空状态，只保留队列状态、筛选、条目与短操作。
- 我的页删除介绍段落、重复状态文案和模拟面试推广，保留进度、音效、简历项目和掌握度。

## 5. 交互与兼容

- 所有节点和 Tab 保持至少 44 点触摸区域。
- 锁定节点禁用；已完成和当前节点均可进入课程。
- 继续兼容 Expo Go，不新增原生依赖。
- 审查绝对定位、隐藏 Modal 和覆盖层，避免再次阻塞点击。

## 6. 验证与交付

- 运行 TypeScript、ESLint、Expo Doctor、Web 导出和 iOS 导出。
- 启动 Web 版本，检查 `/`、`/path` 和主要功能路由。
- 在 390 x 844 手机视口做点击与滚动冒烟测试。
- 根据截图和运行结果迭代修复。
- 仅提交本次计划和实现文件，不包含现有认证日志。
