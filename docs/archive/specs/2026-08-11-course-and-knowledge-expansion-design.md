# Bagu 课程与知识库扩充设计

日期：2026-08-11

## 目标

把 Bagu 从三道 Transformer 单题演示升级为可持续扩充的算法岗学习产品：学习首页是一条完整的 Transformer Section，知识库是可检索、可展开的结构化手册，两者共享概念与来源，但交互职责分离。

## 参考与取舍

- OpenLingo 的 `Unit → 多节课程 → 多题型练习` 证明课程内容应有稳定层级，不能把一个节点等同于一道题。
- OpenTutor 将笔记、测验、闪卡和知识关系拆成独立学习块，说明知识阅读不应被答题门槛阻塞。
- Duolingo 风格路径只借鉴“当前节点突出、按顺序解锁、主题横幅分段”的交互原则，不复制其品牌资产或源码。

## 信息架构

课程数据采用四层结构：

`CourseSection → CourseUnit → Lesson → Exercise`

- 第一版只有一个完整 Section：Transformer。
- Section 包含五个有主题的 Unit。
- 每个 Unit 包含两个 Lesson，Lesson 对应首页上的一个路径节点。
- 每个 Lesson 包含四道 Exercise；完成全部题目后才结算课程进度并解锁下一节点。

五个 Unit 依次为：

1. Attention 基础：Q/K/V、缩放点积、Mask。
2. Transformer 结构：多头注意力、残差、LayerNorm、FFN。
3. 位置与长上下文：正弦位置编码、RoPE、ALiBi、长度外推。
4. 模型架构：Encoder、Decoder、BERT、GPT、T5。
5. 推理与优化：KV Cache、MQA/GQA、FlashAttention、计算与显存复杂度。

## 练习模型

支持四种练习：

- `single-choice`：单选概念辨析。
- `multiple-choice`：多选关键点，只有集合完全一致才算正确。
- `ordering`：排列机制或因果链；第一版用逐项点击生成顺序，支持撤销。
- `self-recall`：口述/默答后展开参考要点，用户按覆盖情况完成自评。

Lesson 页显示题内进度、生命值和即时反馈。答案提交后不能重复改变本题结果；继续按钮进入下一题。最后一题完成后才调用课程完成逻辑并播放完成音效。

## 知识库体验

知识库不再显示“30 秒主动回忆”门槛。列表页使用“领域筛选 + 搜索 + 专题条目”，详情页直接提供阅读结构：

1. 一句话结论与难度。
2. 默认展开的核心原理。
3. 可折叠的直觉理解、公式、关键点、面试回答、常见误区、对比与追问。
4. 相关知识入口。
5. 经典论文或官方资料来源。

第一轮目标至少 50 篇：Transformer 15 篇，LLM/NLP 9 篇，微调与对齐 8 篇，损失函数 7 篇，深度学习 6 篇，强化学习 6 篇。每篇保留 `summary`、`answer`、`intuition`、`keyPoints`、`followUps` 和来源，并新增 `misconceptions`、`relatedIds` 与可选 `comparison`，以便结构化呈现。

## 视觉与交互修复

- 路径节点改为双层圆柱：同色系底座表现侧面，上层圆形面表现按钮；不再用底部边框模拟厚度。
- 按压时上层面向下移动，底座仍在，形成实体按钮反馈。
- 每个 Unit 由独立主题横幅分隔，页面只突出当前 Unit 和当前 Lesson，已完成和锁定节点减少文字。
- 音效开关改为自绘胶囊开关，固定 52×32、24 像素圆形滑块，确保 iPhone 与 Web 对齐一致，并提供 `accessibilityRole="switch"`。

## 状态与兼容

- 继续沿用 lesson id 保存完成状态，旧的三个 lesson id 保持不变，避免现有进度丢失。
- 新课程层级是静态内容数据，不引入后端或登录依赖。
- Review、收藏与简历项目功能保持现有数据格式；知识库新增字段全部有默认兼容路径。
- 无效路由参数显示简短的未找到状态并允许返回，不造成空白页。

## 验证标准

- 数据断言：1 Section、5 Units、10 Lessons、每课 4 题、总计 40 题；知识条目不少于 50，六个领域均达到配额。
- 交互断言：当前节点可点击、锁定节点不可点击、四类题型均可完成、最后一题后才解锁下一课。
- UI 断言：节点无 `borderBottomWidth`，音效胶囊居中且触控区域至少 44×44。
- 工程检查：TypeScript、Expo Lint、Expo Doctor、Web 静态导出、iOS 导出、关键路由 HTTP 冒烟。
- 移动验证：生成新的 Expo Go 二维码，在 iPhone 尺寸下检查路径滚动、答题按钮、知识折叠和音效开关。

## 非目标

本轮不接入 AI 自动出题、云端数据库、账号系统、语音识别或知识图谱画布；内容先以可审查的本地 TypeScript 数据交付。
